# AL HUDA — الهدى

موقع إسلامي عربي RTL بتصميم Premium ومتجاوب مع الهاتف والكمبيوتر.

## الملفات

- index.html: بنية الموقع والأقسام.
- style.css: التصميم والألوان والوضع الليلي.
- script.js: القرآن، التلاوة، المواقيت، القبلة، البحث والتسبيح.

## النشر على GitHub وVercel

1. ارفع الملفات الثلاثة إلى جذر مستودع GitHub.
2. افتح Vercel واربط المستودع.
3. اختر Framework Preset: Other.
4. اترك إعدادات Build Command وOutput Directory الافتراضية المناسبة لموقع Static.
5. اضغط Deploy.

لا يحتاج الإصدار الحالي إلى API key.
